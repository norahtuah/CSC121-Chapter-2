Final Challenge

Student Result System

A program accepts three test marks, calculates the average, and displays PASS when average ≥ 50; otherwise FAIL.

Complete the pseudocode

START
INPUT test1, test2, test3
average = (test1 + test2 + test3) / 
IF average  50 THEN
    OUTPUT average, ""
ELSE
    OUTPUT average, "FAIL"
END IF
END
